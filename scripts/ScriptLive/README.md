# ScriptLive

在 Scripting 里看 B站、斗鱼、虎牙、抖音直播。本脚本移植自 [simple_live](https://github.com/xiaoyaocz/dart_simple_live)（xiaoyaocz，GPL-3.0），本目录同样以 GPL-3.0 发布，许可证见 `LICENSE`。

## 页面

- **首页**：顶部切换平台，双列浏览推荐直播间，下拉刷新、滚到底自动翻页；右上角进入搜索。
- **分类**：平台 → 一级分类 → 子分类图块 → 该分类的直播间。
- **搜索**：键盘点「搜索」提交，可切换平台与「直播间 / 主播」。
- **关注**：按标签筛选，直播中排在最前；下拉或点右上角刷新开播状态，长按或左滑可设置标签、取消关注，「更多」里管理标签。
- **我的**：B站扫码登录、抖音 Cookie、链接解析、观看记录、设置、数据同步和关于。
- **直播间**：上方播放器叠加滚动弹幕，下方是清晰度 / 线路、主播信息与关注按钮，以及「聊天 / SC / 简介」三个面板。弹幕断开时聊天区底部可重新连接。
- **横屏**（iPhone）：直播间允许随手机旋转，横过来进入影院模式——黑底、视频与弹幕铺满整屏，点按画面显示控件，播放中 4 秒无操作自动收起。顶栏可退出全屏、切换清晰度 / 线路，底栏可暂停、刷新、开关弹幕和调整弹幕字号 / 速度 / 区域 / 透明度。开着竖排方向锁定时，点画面右下角的全屏按钮也能横屏；手机转到按钮选择的方向后恢复随手机旋转。离开直播间后恢复 Scripting 里的方向设置。

## 播放器：Pro 原生，免费网页

进入直播间时调用一次 `Script.hasFullAccess()`：

- **Pro 用户**：优先使用原生 `AVPlayer`。先配置音频会话并成功 `setSource()`，再挂载 `AVPlayerView`；站点要求的 Referer / User-Agent（如 B站）随 `setSource` 一起发送。
- **免费用户**：使用 `WebView` 播放器。HLS 交给 `<video>`；FLV 交给随脚本分发的 mpegts.js（需要 iOS 17.1 及以上的 ManagedMediaSource）。页面的 baseURL 设为对应平台网址，CDN 收到的来源是该平台。浏览器拦截带声音的自动播放时会先静音播放，点按画面左下角的「点按开启声音」恢复声音。

`AVPlayer` 不能解码 FLV。Pro 用户遇到只提供 FLV 的清晰度（目前斗鱼全部清晰度都是 FLV）时改用网页播放器，并在「简介」面板说明原因。播放器角标显示当前使用「原生」还是「网页」。

两种播放器都隐藏自带控件，由同一套播放器控件负责暂停 / 继续、全屏和弹幕，弹幕层始终位于视频之上、控件之下。直播暂停后继续播放会重新加载当前线路，直接回到直播进度。

一条线路播放失败会自动换下一条，全部失败后显示错误和「重试」，也可以手动切换清晰度或线路。

## 各平台情况

| 平台 | 播放地址  | 弹幕                        | 说明                                                                                                                                  |
| ---- | --------- | --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| B站  | HLS + FLV | WebSocket，zlib 压缩        | FLV 必须带 Referer，网页播放器优先用 HLS；分类改用 `/room/v3/area/getRoomList`，上游接口匿名访问会返回 -352                           |
| 斗鱼 | FLV       | WebSocket                   | 播放签名按官网脚本的 MD5 流程计算，不执行远端 JS；没有可直接播放的 HLS                                                                |
| 虎牙 | HLS + FLV | WebSocket，TARS 协议        | 优先 HS CDN；个别房间的低码率 HLS 会被 CDN 拒绝，此时可切换线路或清晰度                                                               |
| 抖音 | HLS + FLV | 隐藏 WebView 内的 WebSocket | 弹幕握手必须带 Cookie 和官方签名，在隐藏的 `WebViewController` 中调用官方页面自带的签名函数；搜索需要在「我的 → 抖音」填写登录 Cookie |

## 设置与同步

设置覆盖外观（自动 / 日间 / 夜间）、平台顺序、清晰度（Wi-Fi 与蜂窝分开）、强制 HTTPS、SC 显示、聊天字号、弹幕字号 / 速度 / 区域 / 透明度、屏蔽词（以 `/…/` 包裹按正则匹配）、关注自动刷新与并发数、定时关闭（到时询问是否延迟，10 秒内未选择即退出）。

支持通过 WebDAV 上传与恢复完整备份，也可以导出 / 导入关注 JSON 或完整备份文件。完整备份包含关注、标签、观看记录、屏蔽词、B站账号与脚本设置。

WebDAV 备份路径为 `/ScriptLive/backup.zip`，ZIP 内的文件统一使用 `ScriptLive_*.json` 命名。
