# ScriptLive

在 Scripting 里看 B站、斗鱼、虎牙、抖音直播。本脚本移植自 [simple_live](https://github.com/xiaoyaocz/dart_simple_live)（xiaoyaocz，GPL-3.0），本目录同样以 GPL-3.0 发布，许可证见 `LICENSE`。

## 页面

- **首页**：顶部切换平台，双列浏览推荐直播间，下拉刷新、滚到底自动翻页；右上角进入搜索。
- **分类**：平台 → 一级分类 → 子分类图块 → 该分类的直播间。
- **搜索**：键盘点「搜索」提交，可切换平台与「直播间 / 主播」。
- **关注**：按标签筛选，直播中排在最前；下拉或点右上角刷新开播状态，长按或左滑可设置标签、取消关注，「更多」里管理标签。
- **我的**：B站扫码登录、抖音 Cookie、链接解析、观看记录、设置、数据同步和关于。
- **直播间**：上方播放器叠加滚动弹幕，下方是清晰度 / 线路、主播信息与关注按钮，以及「聊天 / SC / 简介」三个面板。弹幕断开时聊天区底部可重新连接。
- **横屏**（iPhone）：直播间允许随手机旋转，横过来进入影院模式——黑底、视频与弹幕铺满整屏，点按画面显示控件，播放中 4 秒无操作自动收起。顶栏可退出全屏、切换清晰度 / 线路，底栏可暂停、刷新、开关弹幕和调整弹幕字号 / 速度 / 区域 / 透明度。开着竖排方向锁定时，点画面右下角的全屏按钮也能横屏；手机转到按钮选择的方向后恢复随手机旋转。离开直播间后恢复 Scripting 里的方向设置。

## 桌面小组件：直播推荐

在主屏幕添加 Scripting 小组件，长按选择「编辑小组件」，脚本选 ScriptLive。小组件从各平台推荐页挑出正在直播的房间，到点换一批：

- **小号**：整幅直播封面，顶部是「直播中」角标和热度，底部是标题与主播。
- **中号**：立体封面配标题、平台 Logo 与主播、「进入直播间」，底图是同一张封面的模糊放大，右上角是这一轮的时间。
- **大号**：主推横版大卡加三个「更多推荐」，每个直播间都能单独点开。
- **锁屏**：矩形尺寸显示主播与标题，单行尺寸显示主播，圆形尺寸显示图标。

「我的 → 桌面小组件」可以选择推荐来源（综合推荐四个平台轮流挑选，或只看某个平台）和更新频率（30 分钟到每天，默认每小时），并预览三种尺寸。换批从 0 点起按间隔对齐，同一轮里各尺寸看到的是同一批；挑选时越靠前的热门直播越容易入选，上一轮出现过的直播间排到最后。改动设置或外观后小组件立即刷新；到点后的刷新由系统调度，可能稍晚几分钟。

点按直播间会通过 `run_single` 链接打开 ScriptLive，首页出现后直接进入该直播间，关闭直播间回到首页。综合推荐时单个平台请求失败只跳过该平台；全部失败或没有直播时，小组件显示提示并在 15 分钟后重试，单张封面加载失败显示品牌渐变占位。

## 播放器：Pro 原生，免费网页

进入直播间时调用一次 `Script.hasFullAccess()`：

- **Pro 用户**：优先使用原生 `AVPlayer`。先配置音频会话并成功 `setSource()`，再挂载 `AVPlayerView`；站点要求的 Referer / User-Agent（如 B站）随 `setSource` 一起发送。
- **免费用户**：使用 `WebView` 播放器。HLS 交给 `<video>`；FLV 交给随脚本分发的 mpegts.js（需要 iOS 17.1 及以上的 ManagedMediaSource）。页面的 baseURL 设为对应平台网址，CDN 收到的来源是该平台。浏览器拦截带声音的自动播放时会先静音播放，点按画面左下角的「点按开启声音」恢复声音。

`AVPlayer` 不能解码 FLV。Pro 用户遇到只提供 FLV 的清晰度时改用网页播放器，并在「简介」面板说明原因。播放器角标显示当前使用「原生」还是「网页」。

两种播放器都隐藏自带控件，由同一套播放器控件负责暂停 / 继续、全屏和弹幕，弹幕层始终位于视频之上、控件之下。直播暂停后继续播放会重新加载当前线路，直接回到直播进度。

**画中画**（仅原生播放器，需要 Scripting 3.2.2）：点控件栏的画中画按钮，直播进入系统浮窗，可以切到其他 App 继续看；原画面位置显示「正在画中画播放」，点「回到画面内」或浮窗的还原按钮回来。画中画由直播间里的播放器驱动，关闭直播间即结束；浮窗里没有弹幕。切换清晰度或线路、线路失败自动换线时，会先退出画中画再换源。原生播放器以 layer 模式显示画面，锁屏和控制中心的直播信息与播放 / 暂停由脚本提供。网页播放器不支持画中画。

一条线路播放失败会自动换下一条，全部失败后显示错误和「重试」，也可以手动切换清晰度或线路。

## 各平台情况

| 平台 | 播放地址  | 弹幕                        | 说明                                                                                                                                  |
| ---- | --------- | --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| B站  | HLS + FLV | WebSocket，zlib 压缩        | FLV 必须带 Referer，网页播放器优先用 HLS；分类改用 `/room/v3/area/getRoomList`，上游接口匿名访问会返回 -352                           |
| 斗鱼 | HLS       | WebSocket                   | 普通用户与 Pro 共用移动端 HLS 直连，不启动本地服务、不改写清单；免费用户用网页 `<video>`，Pro 用原生播放器                            |
| 虎牙 | HLS + FLV | WebSocket，TARS 协议        | 优先 HS CDN；个别房间的低码率 HLS 会被 CDN 拒绝，此时可切换线路或清晰度                                                               |
| 抖音 | HLS + FLV | 隐藏 WebView 内的 WebSocket | 弹幕握手必须带 Cookie 和官方签名，在隐藏的 `WebViewController` 中调用官方页面自带的签名函数；搜索需要在「我的 → 抖音」填写登录 Cookie |

斗鱼清晰度采用移动端接口开放的档位，标记为「需 App」的档位不显示。默认档统一称为「移动端默认」，避免把接口沿用的「原画2K / 1080P60」名称当作实际画质；2026-10-22 对房间 9999、288016 的分片检查均为 720p / 30 fps，默认、超清、高清可能返回同一路流。该方案不保留桌面接口的全部原画档位，也不另设 FLV 或代理备用链路。

斗鱼签名使用 `homeH5Enc` 下发的官方脚本，在临时、无登录 Cookie 的 `WebViewController` 中配合本地 CryptoJS 执行；网页通过 CSP 禁止网络资源请求，不注册原生消息桥，取到签名后立即释放。随后由脚本请求移动端 `getStreamUrl`，签名或接口失败直接显示错误。网页播放器的 baseURL 同样使用 `https://m.douyu.com/`，与移动端取流来源保持一致。

## 设置与同步

设置覆盖外观（自动 / 日间 / 夜间）、平台顺序、桌面小组件（推荐来源与更新频率）、清晰度（Wi-Fi 与蜂窝分开）、强制 HTTPS、SC 显示、聊天字号、弹幕字号 / 速度 / 区域 / 透明度、屏蔽词（以 `/…/` 包裹按正则匹配）、关注自动刷新与并发数、定时关闭（到时询问是否延迟，10 秒内未选择即退出）。

支持通过 WebDAV 上传与恢复完整备份，也可以导出 / 导入关注 JSON 或完整备份文件。完整备份包含关注、标签、观看记录、屏蔽词、B站账号与脚本设置。

WebDAV 备份路径为 `/ScriptLive/backup.zip`，ZIP 内的文件统一使用 `ScriptLive_*.json` 命名。

## 第三方组件

- `assets/platforms/*.png`：B站、斗鱼、虎牙、抖音的原始 PNG Logo；平台标识版权归对应平台所有。
- `assets/mpegts.js`：mpegts.js 1.8.2，Apache-2.0，许可证见 `assets/mpegts.LICENSE` 与 `assets/mpegts.js.LICENSE.txt`。
- `assets/crypto-js/core.js`、`assets/crypto-js/md5.js`：[CryptoJS 4.2.0](https://github.com/brix/crypto-js/tree/4.2.0)，仅使用核心与 MD5 模块，MIT，许可证见 `assets/crypto-js/LICENSE`；供斗鱼网页签名使用。

直播内容版权归各平台及主播所有，本脚本仅供学习交流。
