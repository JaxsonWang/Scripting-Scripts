## v1.0.3

1. 修复读取网络状态时调用不存在的 API；通过网络接口近似选择 Wi-Fi / 蜂窝清晰度，读取失败时保留默认设置
2. 调整虎牙线路优先级：HLS 按 TX → AL → HS，FLV 按 TX → HS → AL 排序，保留备用线路
3. 虎牙弹幕改用 WebKit 连接，修复原生 WebSocket 的协议错误；收到服务器推送后才显示连接正常
4. 补齐网页进程异常退出后的处理：播放器换线或重试时重新加载页面，虎牙弹幕显示断开提示并支持重新连接
5. 播放加载时显示当前尝试的线路，手动重试清除旧错误，避免旧连接回调干扰新连接

## v1.0.1

1. 支持横屏播放
2. 支持视频画中画
3. 新增桌面小组件「直播推荐」，支持小、中、大号和锁屏尺寸，可在「我的 → 桌面小组件」选择推荐来源和更新频率（默认每小时换一批）
4. 斗鱼改用移动端 HLS 直连，普通用户与 Pro 共用取流方案；移除 HttpServer 本地代理，免费用户用网页播放器，Pro 用原生播放器并支持画中画。清晰度以移动端开放档位为准，不保留桌面端的全部原画档位
5. 向下兼容 iOS17 白屏的问题

---

目前就 Scripting 开通 pro 有满血功能，可以调用 AVPlayer 原生播放器直播，并且无论在竖屏还是横屏下弹幕功能正常的。
非 Pro 用户只能使用 Webview Video 网页视频播放直播，弹幕功能没那么好。
